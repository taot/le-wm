每个 knot 对损失的贡献

N · wk · err(tk)。所有柱子加起来 = SIGReg。灰色曲线是窗口 e−t²/2 的形状。

  • 纵轴：上限 = max(1, 最高的柱子) × 1.1，所以上限是 1.1 时，每根柱子都小于 1。
  • 灰色曲线：只显示权重怎样随 t 下降。它被缩放到面板高度，不使用柱子的纵轴刻度。
  • 为什么先升高后下降：每根柱子 = err(t) × 权重。err(t) 随 t 增大（t = 0 时所有点在 (1, 0)，err 一定是 0）；权重 wk = 梯形系数（两端 Δt，中间 2Δt）× e−t²/2 随 t 减小（t = 3 时只有约 0.011）。两者相乘，得到中间高、两边低的形状。
  • 完美的 N(0,1) 也有这个形状：只有 N 个样本，重心会随机抖动。噪声的期望是 E[N·err(t)] = 1 − e−t²，所以纯噪声的柱子 ≈ 2Δt · e−t²/2 · (1 − e−t²)。最大值在 t = √ln3 ≈ 1.05。这个值和 N 无关。
  • 所以：峰的位置不一定说明 t ≈ 1 有问题。柱子的高度和样本有关，按「重新采样」高度会改变很多，但形状大致不变。对 N(0,1)，所有柱子的总和（即 SIGReg）平均约为 1.0。
  • 比较分布：坍缩 / 太宽 / 偏移在小 t 和中等 t 就有大偏差，峰在左边，柱子很高。均匀 / 双峰 / Laplace 的偏差在较大的 t 才出现，峰向右移动，但窗口在右边很小，所以它们在损失中的权重小很多。
  • 窗口的作用：SIGReg 主要惩罚低阶错误（均值、方差），对高阶形状差异惩罚较轻，因为大 t 的估计噪声更大。

怎样读这个页面

  • t 小：所有点挤在角度 0 附近，重心靠近 (1, 0)。
  • t 变大：点沿圆散开，重心向圆心收缩。对 N(0,1)，重心刚好以 e−t²/2 的速度收缩。
  • 坍缩：点不散开，重心停在 (1, 0) 附近，比目标大。
  • 太宽：点散开太快，重心收缩太快。
  • 偏移：整个点云旋转 t·μ，Im 不再是 0。
  • 双峰 / 均匀 / Laplace：均值和方差都正确。小 t 看不出差异，只有较大的 t 能发现。

err(t) = (Re φ̂ − e−t²/2)² + Im φ̂²，即重心到目标点距离的平方。

对应 module.py：

x_t = (proj @ A)[..., None] * t
err = (cos.mean − phi)² + sin.mean²
stat = (err @ weights) * N

真实训练中，A 有 1024 个随机方向，每个方向做一次这个一维检验，然后取平均。由 Cramér–Wold 定理，所有一维投影都是 N(0,1) ⇔ 整体是各向同性高斯。

为什么用特征函数

  • 可微：只用 cos 和 sin，梯度可以直接回传。
  • 有界：每个点都在单位圆上，一个离群值的影响最多是 1/N。直接匹配高阶矩（如 x⁴）时，离群值的影响会非常大。
  • 不需要分箱：和直方图不同，没有 bin 宽度这个超参数。
  • 完全确定分布：两个分布的特征函数相同 ⇔ 两个分布相同。

一句话：特征函数就是"把样本以 t 倍速绕圆排开后的重心"。SIGReg 要求在 t ∈ [0, 3] 的每个位置，这个重心都和标准高斯的重心 (e−t²/2, 0) 重合。
