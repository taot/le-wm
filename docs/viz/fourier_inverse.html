1. 两个公式

正变换把 f 拆成很多个频率的波。逆变换把这些波加回去，得到原来的 f。

正变换F(t) = ∫ f(x) · eitx dx
逆变换f(x) = (1/2π) ∫ F(t) · e−itx dt
  • t 是频率。 F(t) 是一个复数。它的大小说明"f 中频率 t 的成分有多少"，它的角度说明这个波的相位（位置）。
  • 这里使用和特征函数一样的符号（e+itx）。如果 f 是概率密度，F 就是特征函数 φ。
  • f 是实数时，F(−t) 是 F(t) 的共轭。所以 t < 0 的部分没有新的信息，图中只画 t ≥ 0。

2. 正变换：用波去"探测" f

eitx = cos(tx) + i·sin(tx)。所以对每一个 t：

  • 把 f(x) 乘上 cos(tx)，求面积 → Re F(t)。
  • 把 f(x) 乘上 sin(tx)，求面积 → Im F(t)。

如果 f 的形状和波的"节奏"一致，乘积的正面积和负面积不会抵消，结果大。如果不一致，正负互相抵消，结果接近 0。

3. 逆变换：把波一个一个加回去

4. 为什么逆变换是唯一的

"唯一"的意思是：如果你知道所有 t 的 F(t)，那么 f 只有一种可能。换一种说法：没有两个不同的函数有相同的 F。

第 1 步：把问题变简单

傅里叶变换是线性的：(f − g) 的变换 = Ff − Fg。所以，如果 f 和 g 的变换相同，那么差 d = f − g 的变换在每个 t 都是 0。

所以只需要证明一件事：变换处处为 0 的函数，只有 0 函数。也就是说：不存在一个不是 0、但所有的波都"看不见"的函数。

下面用三个角度说明为什么这样的"隐形函数"不存在。

第 2 步：不同频率的波互相"垂直"

把两个波 cos(sx) 和 cos(tx) 乘起来，在一个长的区间 [−L, L] 上求平均：

  • s ≠ t：乘积正负交替，平均值趋向 0。这两个波"垂直"（正交）。
  • s = t：乘积是 cos²，一直 ≥ 0，平均值不是 0。

怎样读右图：它显示两个波 cos(sx) 和 cos(tx) 有多"像"，作为 s 的函数。

  • 横轴是 s；虚线是固定的 t；黑点是当前的 s（左图使用的 s）。
  • 纵轴是乘积在 [−L, L] 上的平均值 × 2。乘 2 是为了让 s = t 时的值约等于 1。公式是 sinc((s − t)·L) + sinc((s + t)·L)，sinc(u) = sin(u)/u。s ≥ 0.5 时第二项很小，所以形状主要来自第一项。
  • 主峰在 s = t，高度约为 1：频率相同时，乘积是 cos²，一直 ≥ 0。
  • 旁瓣：s ≠ t 时，值在 0 附近振荡，并以 1/(|s − t|·L) 的速度变小。零点在 s = t ± kπ/L，主峰的宽度是 2π/L。

为什么 s ≠ t 时值不一定是 0？乘积可以拆成两个波：

cos(sx)·cos(tx) = ½·cos((s − t)x) + ½·cos((s + t)x)

快的部分 cos((s + t)x) 在区间中振荡很多次，正负几乎完全抵消。慢的部分 cos((s − t)x) 是一个"拍"，也就是左图中的包络。如果 s 和 t 很接近，这个拍在 [−L, L] 中还没有完成一个周期，所以正负不能完全抵消。例如 t = 3.5、s = 3.05、L = 10 时，(s − t)·L ≈ −4.5：包络在中间是正的，在两边是负的，负的稍多，所以平均值 ≈ −0.22。这刚好是 sinc 最深的旁瓣（u ≈ 4.49，值 −0.217）。

所以，"不同频率的波正交"只在 L → ∞ 时才完全成立。L 有限时，两个很接近的频率不能完全分开。

L 变大时：旁瓣按 1/L 变小，主峰按 1/L 变窄，高度保持为 1。极限是：s = t 时是 1，其他位置都是 0。如果不求平均，只求积分（再乘 2L），峰的高度按 2L 增大，宽度按 1/L 变小，面积保持为 2π。这就是 δ 函数：

∫ ei(t−s)x dx = 2π · δ(t − s)

和唯一性的关系：这就是逆变换"选出"一个频率的方法。把信号乘上频率 s 的波再积分，只有频率等于 s 的成分会保留，其他成分都互相抵消。每个频率都可以这样干净地分开，所以 f 中每个频率的成分都是确定的，f 也就确定了。

频率分辨率：主峰的宽度 2π/L 说明，只看长度 2L 的区间时，相差小于约 π/L 的两个频率分不开。这又是不确定性原理：x 中看得越宽，t 中分得越细。

试一试：设 t = 3.5、L = 10，把 s 设为 t + π/L ≈ 3.81：黑点在 0 上（第一个零点）。 然后把 s 设为 3.05：黑点在最深的旁瓣上。保持 s，把 L 加大到 40：黑点几乎回到 0，主峰变得很窄。

直观的类比：在三维空间里，如果你知道一个向量在 x、y、z 三个互相垂直的方向上的投影，这个向量就完全确定了。F(t) 就是 f 在"频率 t 这个方向"上的投影。不同的 t 互相垂直，而且这些方向足够多，可以组成任何函数（这叫"完备"）。所以所有投影都知道时，f 就确定了。

有限维的版本：如果 f 只有 N 个点，傅里叶变换就是一个 N × N 的矩阵（DFT 矩阵）。它的各列互相正交，所以矩阵可逆，逆矩阵就是逆变换。N 个系数唯一确定 N 个值。连续的傅里叶变换是 N → ∞ 的版本。

第 3 步：能量守恒——任何改变都会留下痕迹

我们要证明什么：如果 d 不是 0，那么至少有一个 t 使 D(t) ≠ 0。也就是说，不存在一个"所有频率都看不到"的改变。

(a) 先看三维空间：勾股定理。一个向量 v 在三个互相垂直的方向上的坐标是 c1、c2、c3。它的长度满足：

|v|² = c1² + c2² + c3²

这个公式有两个重要的性质：

  • 它只对互相垂直的方向成立。如果方向不垂直，还会有交叉项 2c1c2·cos(夹角)。
  • 右边每一项都 ≥ 0，不能互相抵消。所以如果所有坐标都是 0，长度就是 0，向量就是 0。只要向量不是 0，至少有一个坐标不是 0。

(b) 函数也一样。把函数看成一个"有无穷多个分量的向量"。它的"长度的平方"叫做能量：∫ d(x)² dx。逆变换说，d 是很多个波的和：

d(x) = (1/2π) ∫ D(t) · e−itx dt

D(t) 就是 d 在"频率 t 这个方向"上的坐标。现在计算能量 ∫|d|² dx：这是"波的和"乘以"波的和"，展开以后有很多交叉项。依据第 2 步，不同频率的两个波相乘再积分，结果是 0，所以所有交叉项都消失，只剩下每个频率和自己的乘积。结果是：

∫ |d(x)|² dx = (1/2π) ∫ |D(t)|² dt

这就是 Plancherel 定理。它是无穷维的勾股定理："总能量 = 每个频率的能量之和"，没有交叉项。傅里叶变换就像把坐标轴旋转到一组新的垂直方向（波），旋转不改变长度。

(c) 结论。右边的 |D(t)|² 每一点都 ≥ 0，不能互相抵消。所以：

  • 如果 D(t) 处处为 0，右边是 0，所以 d 的能量是 0，所以 d = 0。这就是第 1 步需要的结论。
  • 反过来说，d 有多少能量，频谱中就正好有多少能量。能量可以移到不同的频率，但是不能消失。
为什么要用能量（平方），而不直接用面积 ∫d dx？因为面积可以正负抵消：一个有正有负的改变，面积可以是 0（这时 D(0) = ∫d dx = 0）。而能量是平方的和，只要 d 在某个地方不是 0，能量就一定大于 0。

包络 e−(x−a)²/(2w²) 决定它在哪里（a）、有多宽（w）；cos(ωx) 决定它振荡得多快（ω）。

"不隐形"和"看得到"是两件事。第 3 个试验中，改变没有隐形，它的全部能量都在频谱中。但是如果你只看 t ∈ [0, 3]（像 SIGReg 一样），你几乎看不到它。所以唯一性需要知道所有 t 的 F(t)（见第 5 节）。

第 4 步：一个可以直接计算的还原方法（高斯模糊）

还有一个更具体的证明，它也是概率论中证明"特征函数唯一确定分布"的方法（Lévy 反演公式）：

  1. 把 F(t) 乘上一个窗口 e−σ²t²/2，再做逆变换。
  2. 得到的结果正好是 f 被宽度为 σ 的高斯模糊以后的样子：f ∗ N(0, σ²)。
  3. 这个计算只用到 F。所以如果 f 和 g 的 F 相同，它们在每个 σ 的模糊结果也相同。
  4. σ → 0 时，模糊消失，结果就是 f 本身。所以 f = g。

为什么要加窗口，而不直接用逆变换公式？因为对有些分布，F(t) 下降很慢（例如均匀分布的 F 像 1/t），对一个点质量（Dirac δ），|F(t)| 一直是 1，根本不下降。这时 ∫F(t)e−itxdt 不收敛。乘上窗口以后，积分一定收敛，然后再让 σ → 0。

和 SIGReg 的关系：SIGReg 计算 ∫ |φ̂(t) − φ(t)|² · e−t²/2 dt。因为 |D|² · e−t²/2 = |D · e−t²/4|²，这等于先把两个分布的差用宽度 σ = 1/√2 的高斯模糊，再用第 3 步的能量守恒求它的能量。所以 SIGReg 只比较"模糊以后"的分布：比模糊宽度更细的差异，它几乎看不到。

5. "唯一"的准确意思和两个注意点

几乎处处唯一

如果只改变 f 在一个点（或者几个点）的值，积分不会改变，所以 F 也不会改变。所以准确地说：F 唯一确定 f，但是不区分这种"不影响任何积分"的差别。对概率分布来说，这正好就是"分布相同"。

必须知道所有的 t

上面的所有论证都需要知道每一个 t 的 F(t)。如果只知道一部分 t，就不唯一了：

  • 只知道 t ∈ [0, T]：频率高于 T 的部分看不到。第 4 节第 3 步中 ω = 8 的波包就是一个例子：它在 [0, 3] 中几乎没有能量。
  • 只知道等间距的点 tk = k·Δ：如果 d(x) = h(x) − h(x − 2π/Δ)，那么 D(tk) = H(tk)·(1 − ei·2πk) = 0。也就是说，把一部分质量平移 2π/Δ，在这些点上看不出来（混叠）。SIGReg 中 Δ = 3/16，所以 2π/Δ ≈ 33.5。

所以，SIGReg 用 17 个 knot 时，"所有 knot 上都匹配"只是一个必要条件，不能完全保证分布是 N(0,1)。但是它对最重要的低阶错误（均值、方差、坍缩）非常敏感，而且训练中使用很多个随机方向，所以在实际中效果很好。

6. 和 SIGReg 的关系

  • 特征函数 φ(t) 就是概率密度的傅里叶变换（第 1 节）。
  • 因为逆变换是唯一的，所以"对所有 t，φ̂(t) = e−t²/2" ⇔ "分布就是 N(0,1)"。这就是 SIGReg 可以用特征函数检验高斯性的原因。
  • SIGReg 的窗口 e−t²/2 等于"先把差用宽度 1/√2 的高斯模糊，再求能量"（第 4 节第 4 步）。依据第 3 步的能量守恒，这相当于在 x 空间中用宽度为 1 的高斯核 exp(−(x−y)²/2) 比较两个分布（MMD，Epps–Pulley 检验）。
  • SIGReg 只用 t ∈ [0, 3] 中的 17 个点，所以它是一个近似的检验（第 5 节）。
